## 1. 本轮挖掘结论

PixelSigns.art 不建议第一阶段同时覆盖大量 AI 主题。

更值得优先研究的三个 Cluster：

1.  **AI × English Learning：Checker / Evaluator / Practice**
2.  **AI Writing / Communication：针对非母语用户的即时反馈**
3.  **AI Utility：Prompt / Text / Decision / Analysis 类小工具**

其中，**AI × Language Learning**
是最值得深入验证的交叉方向：它既符合今天 AI Tool
的搜索行为，又可以自然给现有语言学习业务导流。

当前市场也证明"AI speaking practice""AI writing
feedback"等需求已经形成实际产品类别：British Council 已提供 AI speaking
activities；市场上也存在 TalkDrill、Contexta、EchO 等 AI
英语口语产品。2026 年仍有多项研究关注 AI 对 EFL/ESL
写作反馈的应用，说明该需求并非单纯 SEO
造词，而是存在持续的真实使用场景。

# 3. 完整候选池：45 个关键词

## Cluster A --- English Level / Assessment

### 1. AI English level checker

**用户任务：** 粘贴文字或完成短测试，判断英语水平。\
**Tool：** 输出 CEFR A1--C2 区间、Grammar / Vocabulary / Coherence
子评分、薄弱项和下一步训练建议。\
**导流：** 测评结果 → 个性化语言学习产品。\
**价值：** 很强。

### 2. English level checker

Tool 与 #1 相同，但这是更宽泛的非 AI 表达。

### 3. English level test AI

提供动态题目 + AI 评估，而不是传统固定选择题。

### 4. CEFR level checker

输入 Writing / Speaking Sample，给出"estimated CEFR
range"，并明确说明它不是官方认证考试。

### 5. writing level checker

分析用户英文写作的大致难度和水平。

### 6. English writing level checker

更明确针对 ESL / EFL 学习者。

### 7. vocabulary level checker

通过 adaptive quiz 或文本样本估算 vocabulary range。

### 8. English grammar level test

不是简单"改语法"，而是诊断用户经常犯的语法类型。

**推荐 Tool：**

> **AI English Level Checker**

MVP：

``` text
Paste 100–500 words
        ↓
AI Analysis
        ↓
Estimated CEFR: B1–B2
        ↓
Grammar       B1
Vocabulary    B2
Clarity       B1
Complexity    B1
        ↓
Top 3 weaknesses
        ↓
7-day improvement plan
```

这是很适合向语言学习产品导流的入口。

### 32. English tone checker

Formal / Casual / Friendly / Direct / Polite。

### 33. English clarity checker

判断表达是否清晰。

### 34. ESL writing checker

直接锁定学习者。

**推荐 Tool：**

> **English Naturalness Checker**

它与传统 Grammar Checker 的区别：

``` text
Grammar Checker:
Is it grammatically correct?

Naturalness Checker:
Would a fluent English speaker actually say it this way?
```

示例：

``` text
Input:
I very like this movie.

Output:
❌ Not natural

Better:
I really like this movie.

Why:
"Very" normally doesn't modify the verb "like".

More natural:
I really enjoyed this movie.
```

这个 Tool 有一个明显优势：

> **它不是单纯复制 Grammarly，而是解决 ESL
> 用户"语法可能没错，但说得不像自然英语"的问题。**

值得重点验证 SERP。

# 14. SERP 人工分析方法

每个候选词都实际搜索 Google。

记录 Top 10：

``` text
Position
Domain
DR
Page Type
Tool / Article
Page Age
Content Quality
Tool Quality
Exact Intent Match
Backlinks
```

尤其寻找：

### Signal 1 --- 小站进入 Top 10

意味着 Domain Authority 门槛可能没有想象中高。

### Signal 2 --- Reddit / Quora / Forum

可能说明 Google 找不到足够好的专用页面。

### Signal 3 --- 大量 Article，但 Query 明显是 Tool Intent

这是非常值得注意的机会。

### Signal 4 --- 已有 Tool 很差

例如：

``` text
必须注册
加载慢
结果很浅
广告很多
Mobile UX 差
没有 Explanation
```

可以用产品质量竞争。

### Signal 5 --- SERP 被 5--8 个大品牌完全占据

即使 KD 显示不高，也谨慎进入。
